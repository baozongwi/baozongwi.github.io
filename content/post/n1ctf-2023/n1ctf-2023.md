public function makeOptional(array $parameters = [])
{
    $originalContents = file_get_contents($parameters['viewFile']);

很显然是可以打 php-filter-chain，但是`viewFile` 不是 include，需要 Ignition 先读出来，过一遍 token 检查，再写回同一个文件。

生成方式和陆队博客写的 php filter chain 一样，先用 `UTF-8 -> ISO-2022-KR` 在内容前面塞进 `\x1b$)C`，base64 之后只剩下一个字符 `C`，再用每一组 iconv 往 base64 前面补一个字符，补完之后做一次 base64-decode，得到的就是我们要的 PHP，后面跟着原来文件的脏数据。这题的 PHP 是 glibc，这组过滤器能创建。有两个点要自己处理：

- 过滤器写成 `read=`。不写的话，`file_put_contents` 写回去时同一套链会再跑一遍，内容被写坏。
- payload 末尾加 `__halt_compiler()`。脏数据还在，但 PHP 不再解析它。

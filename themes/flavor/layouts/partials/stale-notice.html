{{- /* Posts older than staleDays (default 100) get a top-of-article note. Freshness uses lastmod when set, otherwise date — bump lastmod and the note goes away until another staleDays pass. The day count is never rendered by Hugo: writing now-date into the HTML would change every stale page on every build, even with no content change. The markup therefore carries the threshold only ("over N days", which is always true when the notice is emitted) and the script replaces it with the exact count, dropping the notice entirely if the post has since been refreshed. */ -}} {{- if and .IsPage (eq .Type "post") (ne .Params.stale false) -}} {{- $minDays := 100 -}} {{- with .Site.Params.staleDays -}}{{- $minDays = int . -}}{{- end -}} {{- $fresh := .Lastmod -}} {{- if $fresh.IsZero -}}{{- $fresh = .Date -}}{{- end -}} {{- if not $fresh.IsZero -}} {{- $ageDays := div (sub now.Unix $fresh.Unix) 86400 -}} {{- if gt $ageDays $minDays -}}

Last updated over {{ $minDays }} days ago — this post may be out of date, read with care.

{{- end -}} {{- end -}} {{- end -}}
